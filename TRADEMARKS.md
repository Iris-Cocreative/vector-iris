# Vector Iris name and mark

The code in this repository is open source under the Apache License 2.0. The
**name "Vector Iris"** and the **Vector Iris mark** (the spectrum eye) are not.
Apache 2.0 does not grant trademark rights (section 6), and this page explains
what that means in practice.

## You can

- Use, modify and redistribute the code, including commercially, under the
  Apache 2.0 terms.
- Say your project is "based on Vector Iris" or "a fork of Vector Iris", and
  link back here.
- Refer to Vector Iris by name when writing about it, reviewing it or teaching it.

## Please don't, without written permission

- Publish a modified build under the name "Vector Iris", or a confusingly
  similar name, or with the Vector Iris mark.
- Suggest that Iris Cocreative made, endorses or supports your version.

If you fork it, give your version its own name and mark, and change the
extension ID in `CSXS/manifest.xml` (`com.iriscocreative.vectoriris`) so it
can be installed side by side with the original.

Questions or permission requests: open an issue on this repository.
